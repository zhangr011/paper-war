# Issue 14: Client rendering: 7 unit types as colored shapes + tests

## Parent

`.scratch/v1-design-overhaul/PRD.md`

## What to build

Update the WebGL client to render 7 distinct CombatUnitTypes as different colored shapes. The client receives CombatUnitType and IsCommander from the extended snapshot protocol (issue 13).

Shape/color mapping:
- Light Infantry: small green circle
- Heavy Infantry: small orange circle
- Sniper: small blue triangle
- Anti-Armor Infantry: small red triangle
- Motor Gun: medium green square
- Motor Artillery: medium orange square
- Motor Missile: medium red square
- Commander: rendered in its type's shape with a white border/outline

Light units (circle/triangle) are smaller than Heavy units (square). The shape encodes armor type (circle/triangle = Light, square = Heavy). The color encodes weapon type (green = Gun, orange = Cannon, blue = Sniper, red = Missile).

Remove Morale-based rendering (no morale bar, no morale color tinting). Remove any melee/ranged visual distinction — replaced by the type system.

## Acceptance criteria

- [ ] Each of the 7 CombatUnitTypes renders as a distinct shape+color combination

- [ ] Armor type determines shape (Light=circle/triangle, Heavy=square)
- [ ] Infantry types use circles, specialist types use triangles

- [ ] Melee/ranged visual distinction removed
