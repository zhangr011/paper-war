# Issue 01: CombatUnitType definitions + Damage Matrix + tests

## Parent

`.scratch/v1-design-overhaul/PRD.md`

## What to build

Define the foundational type system for all combat units. Create WeaponType and ArmorType enums, a CombatUnitType enum with 7 entries, a stats lookup table mapping each type to its weapon, armor, cost, HP, damage, range, cooldown, recruit cost, and kill bounty. Create a DamageMultiplier lookup function implementing the 4x3 damage matrix (Gun/Cannon/Sniper/Missile vs Light/Heavy/Building). Create a CanDamageTerrain helper that returns true for Cannon and Missile only.

This is the data foundation that every other system depends on. No ECS integration yet — pure data definitions and lookup functions.

CombatUnitType stats:

- Light Infantry: Gun/Light, cost 1, HP 80, Dmg 15, Range 5, CD 3, Recruit 15g, Bounty 12g
- Heavy Infantry: Cannon/Light, cost 2, HP 60, Dmg 25, Range 7, CD 5, Recruit 25g, Bounty 20g
- Sniper: Sniper/Light, cost 1, HP 40, Dmg 45, Range 10, CD 8, Recruit 50g, Bounty 40g
- Anti-Armor Infantry: Missile/Light, cost 2, HP 60, Dmg 35, Range 8, CD 6, Recruit 30g, Bounty 24g
- Motor Gun: Gun/Heavy, cost 2, HP 120, Dmg 15, Range 5, CD 2, Recruit 25g, Bounty 20g
- Motor Artillery: Cannon/Heavy, cost 4, HP 150, Dmg 40, Range 7, CD 5, Recruit 50g, Bounty 40g
- Motor Missile: Missile/Heavy, cost 4, HP 130, Dmg 50, Range 9, CD 7, Recruit 60g, Bounty 48g

Damage matrix (stored as percentages where 100 = 1.0x):

| | Light | Heavy | Building |
|---|---|---|---|
| Gun | 100 | 50 | 0 |
| Cannon | 50 | 100 | 25 |
| Sniper | 150 | 25 | 0 |
| Missile | 25 | 150 | 25 |

Sniper/Heavy does not exist as a CombatUnitType.
