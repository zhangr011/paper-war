# Issue 08: Map generator constraints + Objective types + tests

## Parent

`.scratch/v1-design-overhaul/PRD.md`

## What to build

Update the map generator to enforce v1 constraints. Add an Objective field to GameMap with type-specific data.

Map generator constraints:
- Road-connected spawns guaranteed: both spawn areas must have road tiles connecting to the main road network
- Minimum 3 bridges: the generator must place at least 3 bridges when water features exist
- Shallow water fords: 2-3 fords placed far from bridges (minimum Manhattan distance from any bridge)
- Strongholds indestructible: set Health=0, MaxHealth=0 on stronghold tiles so they cannot be destroyed
- Walls can cross roads: the generator may place wall tiles that intersect road tiles

Objective types added to GameMap:
- ObjectiveElimination: no data, ends when one faction has no living entities
- ObjectiveCapture: TargetX, TargetY (stronghold tile), HoldTarget (300 ticks), HoldCounter (current progress)
- ObjectiveSurvival: Duration (per-map timer in ticks), player wins if all AI eliminated before timer

Each generated map randomly picks an objective type. Map generator tests verify constraints.
