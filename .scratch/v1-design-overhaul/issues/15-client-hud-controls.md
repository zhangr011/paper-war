# Issue 15: Client HUD: Gold counter, Recruit button, AttackGround mode, tactical orders

## Parent

`.scratch/v1-design-overhaul/PRD.md`

## What to build

Add a minimal HUD overlay to the WebGL client with:

- Gold counter: displays PlayerGold from snapshot in the top-right corner
- Recruit button: keyboard shortcut R. When pressed, opens a simple type selector (1-7 keys to pick CombatUnitType). Sends Recruit command to server.
- AttackGround mode: keyboard shortcut G. Toggles AttackGround mode. In this mode, the next right-click on terrain sends an AttackGround command at that tile position. Visual indicator shows when AttackGround mode is active.
- Tactical orders: keys 1-4 for Follow, Charge, Retreat, Hold. Sends tactical order to server for the selected Squad.
- Left click: select Squad (click on own units)
- Right click: context action (move to location, or attack enemy if clicked on enemy unit)

The HUD is rendered as a simple HTML overlay on top of the WebGL canvas — no complex UI framework needed for v1.
