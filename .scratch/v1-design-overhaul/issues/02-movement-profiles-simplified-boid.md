# Issue 02: Movement Profiles + simplified Boid + tests

## Parent

`.scratch/v1-design-overhaul/PRD.md`

## What to build

Replace the single default MovementProfile with two profiles (Light and Heavy) matching the terrain cost tables from the design. Create constructors for each profile. Reduce Boid forces to attraction (toward formation offset from Commander) and separation (from nearby units) only — remove cohesion and alignment weights.

Light profile terrain costs: Plain=1, Road=1, ShallowWater=2, Forest=2, Hill=2, Swamp=2, Snow=2, Desert=2, Bridge=1, Stronghold=1. Impassable: DeepWater, Wall.

Heavy profile terrain costs: Plain=2, Road=1, Forest=4, Hill=4, Snow=4, Desert=4, Bridge=1, Stronghold=1. Impassable: ShallowWater, DeepWater, Swamp, Wall.

Both profiles move at cost 1 on roads, bridges, and strongholds — this keeps mixed squads together on roads.

The UnitTypeComponent (from issue 01) determines which profile a unit uses: ArmorLight → ProfileLight, ArmorHeavy → ProfileHeavy. The session.go SpawnSquad function must assign the correct profile when creating entities.
