Paper War — Clash Map Editor

Dev tool for authoring Clash Maps — the hand-authored 32×32 maps in server/pkg/tilemap/clash_maps.go used by the spectator/balance harness (start_clash). Read-only against game code: paint a map, export Go source to paste back. Spawns and objective are forced at runtime (main.go:348,377-389), so this editor authors terrain + hill elevation only. See ADR-0022 + issue #53.

Preview is structure-only (flat colors + hill elevation shade, reusing the client's terrain palette). Load the exported map in clash mode to judge final art — this is not the textured-terrain shader.
