# Issue 16: Lobby screen: roster view, Commander selection, Start Match button

## Parent

`.scratch/v1-design-overhaul/PRD.md`

## What to build

Create a lobby screen that shows the player's roster, lets them select a Commander, and start a match. This is the pre-match UI.

Lobby screen layout:
- Roster list: shows all Commanders in the player's roster. Each Commander entry shows: CombatUnitType icon (shape+color), Level, Leading Skill, number of attached CombatUnits by type
- Commander detail: when a Commander is selected, show its Formation Template (slots by type), attached CombatUnits list (type, level, kill points)
- "Start Match" button: sends start-match command to server. Server generates random map, creates AI opponent, loads selected Commander's roster into match
- Starter roster notice: if player just got a starter roster, show a brief welcome message

The lobby is an HTML overlay screen. It replaces the WebGL canvas view before match start. On "Start Match", the lobby hides and the match canvas appears.

This is a HITL issue because the lobby UX layout needs human review before implementation is finalized.
