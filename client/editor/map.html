Paper War — Clash Map Editor

Dev tool for authoring Clash Maps — saved as JSON data files under server/data/clash_maps/ (ADR-0033) and loadable by start_clash immediately after Save. Spawns and objective are forced at runtime (main.go), so this editor authors terrain + elevation only. See ADR-0022 / ADR-0033.

Edit view is structure-only (flat colors + elevation shade). Toggle Art (Tab) to preview with the game's actual WebGL terrain shader — water, cliff ledges, hill relief — sharing the same zoom/pan.

Elevation (any terrain)

Paints the tier (0=low, 1=mid, 2=peak) on any terrain. Saved as Elevation. A Δ2 step between neighbouring tiles is a cliff — impassable unless crossed by a Ramp.

Ramp: drag along a cliff edge to connect two tiers. Each ramp tile auto-grades to one tier below its highest neighbour, turning a 2-tier cliff into two walkable 1-tier steps. Brush size applies.
