# Issue 13: Network protocol extension + tests

## Parent

`.scratch/v1-design-overhaul/PRD.md`

## What to build

Extend the network snapshot protocol to include CombatUnitType, Level, Gold, and Objective state. This enables the client to render different unit types, show the Gold counter, and display match objectives.

Changes to UnitSnapshot:
- Add UnitType field (uint8, maps to CombatUnitType enum)
- Add Level field (uint8)
- Add IsCommander flag (bool)

Changes to Snapshot:
- Add PlayerGold field (int32, player's current Gold)
- Add AIGold field (int32, AI's current Gold — may want to hide this, include for now)
- Add ObjectiveType field (uint8)
- Add ObjectiveData field (variable-length, depends on type):
  - Elimination: no data
  - Capture: HoldCounter (int32), HoldTarget (int32)
  - Survival: TimeRemaining (uint32)

Changes to UnitUpdate encoding: extend the changed-flags mask and add new fields. Backward compatibility is not required — v1 client and server update together.

Remove Morale from UnitSnapshot (morale cut from v1).
Remove EventProjectile from EventType.

## Acceptance criteria
