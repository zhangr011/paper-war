# Issue 09: ObjectiveSystem + tests

## Parent

`.scratch/v1-design-overhaul/PRD.md`

## What to build

Create a new ECS system (ObjectiveSystem) that checks win conditions each tick based on the GameMap's Objective type.

Elimination: Scan all alive entities. If one Faction has zero alive entities, the other Faction wins. No timeout. The match runs until one side is wiped.

Capture: Check if any Commander is standing on the target stronghold tile. If the player's Commander is on it, increment HoldCounter by 1. If the AI's Commander is on it, decrement HoldCounter by 1 (minimum 0). If HoldCounter reaches HoldTarget (300 ticks), the holding faction wins. Tug-of-war: both sides can contest.

Survival: Decrement timer each tick. If timer reaches 0 and AI still has alive entities, AI wins. If all AI entities are eliminated before timer expires, player wins.

The system sets a MatchResult flag on the session when a win condition is met. The session stops the tick loop on match end.

## Acceptance criteria

- [ ] Elimination: match ends when one Faction has no alive entities

- [ ] Survival: AI wins if timer expires with AI entities still alive
- [ ] MatchResult flag is set on session when win condition met
